# My First Python Project ❤️

This is my first Python project, built using the basic concepts I’ve learned so far.

The program is a small interactive conversation that asks the user a few questions and responds based on their answers.

## What I Practiced

* Variables
* `input()` and `print()`
* `if`, `elif`, and `else`
* f-strings
* Basic logical flow
* User interaction

## About the Project

Designing the logical flow was challenging and required a lot of trial and error. I’m still working on my problem-solving skills—and clearly, logic isn’t my strongest skill yet! 😂

But that’s exactly what this project is about: learning, experimenting, making mistakes, and improving step by step.

## How to Run

1. Download the `.py` file.
2. Open it with Python or an IDE such as Spyder.
3. Run the program.
4. Answer the questions and see what happens! 😄

This is just the beginning of my Python journey. I’m keeping this project here as a reminder of where I started and how much I can improve over time.
